# Wave-5 CORE symbol set (staged FFI binding)

CORE = the union of the committed M1 access traces covering the primary
OpenTUI workloads (source of truth: opentuiCoreSymbols in
src/zig-symbol-stage.ts):

  - 51 symbols the FFIRenderLib ctor + first native frame touch
    (wave5-symbol-access-trace.json),
  - 4 render-commit trigger symbols (render, renderPartial,
    repaintSplitFooter, commitSplitFooterSnapshot) -> trigger path eager,
  - cold code-streaming path, CodeRenderable cold-1000
    (wave5-symbol-access-trace-stream.json): symbols used between first native
    commit and background full-bind (wave5-cpu-ab finding),
  - warm append path, CodeRenderable warm-1000-append100
    (wave5-symbol-access-trace-stream-warm.json).

Total 78 symbols. Any other symbol is DEFERRED: lazy-bound by the proxy on
first use and pre-bound in the background right after the first native commit.

Provenance: date 2026-08-20 (amended), native-sha
553180957522fcdf2558e899e6d97562555fff238d68d62861a563040008f5cd, bun 1.3.14,
trace fixtures: text (pre-commit) + cold-1000 + warm-1000-append100.
